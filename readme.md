# Fit Tracker

A simple fitness tracking web app built with Flask and Firebase.

## Features
- Register and log in
- Edit your profile
- Track your progress
- Get AI-generated workout and meal plans
- Download plans as PDF

## How to Run Locally
1. Clone the repo
2. Install requirements: `pip install -r requirements.txt`
3. Add your Firebase credentials to `fit-tracker.json`
4. Add your Google API key to `.env`
5. Run: `flask run` or `gunicorn app:app`
